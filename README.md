# Chirag Chauhan portfolio

A responsive React portfolio built with Vite. The site presents Chirag's experience, services, and technical stack without invented project examples.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production files are generated in `dist/`.

## Deploy on Netlify

Import this project from a Git repository, or upload the `dist/` folder manually. The included `netlify.toml` sets the build command to `npm run build` and the publish directory to `dist` for Git-based deployments.

## Edit your content

- Change the text, service cards, and technology list in `src/App.jsx`.
- Change the colors, spacing, and responsive styles in `src/styles.css`.
- Replace the Upwork profile URL in `src/App.jsx` when you have a preferred contact link.
- Update the title and description in `index.html`.

There is no contact form or backend. Both contact buttons open the Upwork profile.
